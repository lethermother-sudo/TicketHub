# TicketHub Marketplace

Esta é a próxima base do projeto: Home + eventos + página de evento + formulário de revenda + estrutura inicial de banco Supabase.

IMPORTANTE: os eventos exibidos no front-end são apenas dados iniciais de demonstração. Para atualização em tempo real e usuários reais, conecte o projeto ao Supabase e substitua o array EVENTS por consultas ao banco.
